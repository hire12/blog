# 🌟 Blog Website - Admin Panel & YouTube Integration 🌟

Welcome to the **Blog Website**! This project provides a modern, sleek, and responsive blogging platform with a powerful **Admin Panel** to easily manage your articles and **YouTube video embedding** for richer content. It’s designed to make blogging and managing content effortless and secure.

---

## 🚀 **Features**

- **Admin Panel**
  Easily **create**, **update**, and **delete** blog posts with a user-friendly admin dashboard.

- **YouTube Integration**
  Embed **YouTube videos** within your articles for better engagement.

- **Responsive & Modern Design**
  A clean, sleek, and mobile-friendly user interface with **Tailwind CSS**.

- **Secure Authentication**
  Admin login system to manage the blog safely with simple login credentials.

- **Dynamic Articles**
  Articles display content dynamically with a rich media experience.

- **Database Management**
  Uses **MongoDB** for storing data and **Prisma** for efficient queries.

## 🛠️ **Tech Stack**

- **Frontend**:
  - **Next.js** for SSR (Server-side rendering)
  - **Tailwind CSS** for responsive and custom styling
  - **TypeScript** for type safety

- **Backend**:
  - **Node.js** & **Express.js** for building APIs
  - **Prisma** ORM for easy database management

- **Database**:
  - **MongoDB** (Cloud-hosted via MongoDB Atlas)

- **Hosting**:
  - **Vercel** for seamless deployment

## 📦 **Installation Guide**

Follow these steps to set up the project locally:

1. **Clone the repository**
   Clone the project to your local machine using the following command:
   ```bash
   git clone https://github.com/hire12/blog.git
   cd your-blog

2. **Install dependencies**
   Install all required dependencies:
   ```bash
   npm install

3. **Configure environment variables**
   Create a .env file in the root of the project and add your MongoDB connection URL:
   ```bash
   DATABASE_URL="mongodb+srv://yourusername:yourpassword@cluster0.mongodb.net/yourdatabase?retryWrites=true&w=majority"

   NEXT_PUBLIC_YOUTUBE_API_KEY="your-youtube-api-key"

4. **Run the development server**
   Start the project locally:
   ```bash
   npm run dev
